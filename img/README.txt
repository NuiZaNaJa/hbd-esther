โฟลเดอร์นี้เก็บรูปสำหรับหน้า "ls /memories" (ห้องภาพ instax)
==============================================================

วิธีใส่รูป:
1) ลากรูปมาใส่โฟลเดอร์นี้ ตั้งชื่อว่า 01.jpg, 02.jpg, 03.jpg ... (หรือ .png / .webp ก็ได้)
2) เปิดไฟล์ js/config.js หาส่วน CONFIG.instax.photos
   - src ชี้ไปที่ไฟล์รูป เช่น src: "img/01.jpg"
   - caption คือคำพูดหวาน ๆ ใต้รูป แก้ได้ตามใจ
3) เพิ่ม/ลดจำนวนรูปได้ตามใจ — แก้รายการใน config แล้วเว็บปรับตามเอง

เคล็ดลับ: รูปแนวตั้ง (สัดส่วนเงยะเกือบจัตุรัส) จะเข้ากรอบ instax สวยที่สุด
ยังไม่ใส่รูปก็เล่นได้อยู่แล้ว การ์ดจะขึ้นว่า "ยังไม่มีรูป" ให้ก่อนนะ

--------------------------------------------------------------
รูปกล้องสำหรับปุ่ม "take photo" (โพลารอยด์ GIF)
--------------------------------------------------------------
วางรูปที่ตัดพื้นหลังแล้ว (ด้านหลังกล้อง instax mini Evo) เป็นไฟล์:
  img/instax-evo.png

- ระบบจะสลับจากกล้องที่วาดด้วย CSS ไปใช้รูปจริงให้เองทันที
- จอ LCD จะถูกวางทับช่องจอสีขาวของรูปให้อัตโนมัติ
  (ถ้าเปิดผ่าน Live Server/http จะตรวจจอให้เองเป๊ะ ๆ
   ถ้าเปิด file:// แล้วจอเยื้อง ให้แก้ตัวเลข --lcd-x / --lcd-y /
   --lcd-w / --lcd-h ที่ .cam-face ใน css/style.css)
